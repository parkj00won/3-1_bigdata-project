# 프로젝트 문제정의

## 1. 선택한 데이터

- **데이터 이름:** Data Science Job Postings & Skills Dataset
- **출처:** Kaggle  
  - URL: https://www.kaggle.com/  
  - 세부 데이터셋 URL은 최종 선택한 Kaggle 데이터셋 페이지 링크로 기입 예정
- **라이선스:** Kaggle 데이터셋 페이지에 명시된 라이선스 기준 확인 예정
- **데이터 형식:** CSV
- **데이터 크기:** 약 수천~수만 행, 여러 개의 열로 구성된 표 형식 데이터
- **주요 컬럼 예시**
  - `Job_Title`: 채용 직무명
  - `Skills_Required`: 요구 기술 스택
  - `Job_Description`: 채용공고 설명
  - `Company`: 기업명
  - `Location`: 근무 지역
  - `Salary`: 연봉 또는 급여 정보

---

## 2. 풀고 싶은 문제

AI·데이터 직무를 준비하는 학생들은 Data Analyst, Data Scientist, Data Engineer, AI/ML Engineer 등 직무별로 어떤 기술을 우선적으로 학습해야 하는지 판단하기 어렵다.  
채용공고마다 요구하는 기술 스택이 다르고, 직무명은 비슷해 보여도 실제로 필요한 역량에는 차이가 있기 때문이다.

따라서 **채용공고 데이터로 AI·데이터 직무별 요구 기술 스택을 분석하고, 사용자의 보유 기술을 기반으로 가장 적합한 직무와 보완해야 할 기술을 추천하고 싶다.**

- **활용 데이터:** 채용공고 데이터
- **분석 목적:** 직무별 핵심 기술 스택 분석 및 개인 맞춤 직무 추천
- **예측/분류 대상(target):** `Job_Title`
- **입력 데이터(feature):** `Skills_Required`를 전처리한 기술 스택 원-핫 인코딩 값

---

## 3. 만들 서비스(완성 모습)

Streamlit을 활용하여 사용자가 자신의 보유 기술을 입력하면 적합한 AI·데이터 직무와 부족한 기술을 보여주는 웹 서비스를 만든다.

### 사용자 입력

사용자는 웹 화면에서 본인이 보유한 기술을 체크박스로 선택한다.

예시 입력:

- Python
- SQL
- Tableau
- AWS
- TensorFlow
- PyTorch
- Docker
- Excel
- Power BI
- Spark

### 서비스 출력

사용자가 기술 스택을 선택하고 분석 버튼을 누르면 다음과 같은 결과를 보여준다.

1. 사용자의 기술 스택과 가장 유사한 추천 직무
2. 직무별 적합도 또는 예측 확률
3. 해당 직무에서 자주 요구되지만 사용자가 아직 보유하지 않은 부족 기술
4. 전체 채용공고 기준 핵심 기술 스택 Top 10 시각화
5. 직무별 요구 기술 스택 비교 그래프

### 예시 결과

> 사용자의 현재 기술 스택은 **Data Analyst** 직무와 가장 유사합니다.  
> 현재 입력한 기술 기준 예상 적합도는 **82%**입니다.  
> 추가로 학습하면 좋은 기술은 **Power BI, Statistics, Excel**입니다.

### 사용할 기술

- **웹 서비스:** Streamlit
- **데이터 분석:** Pandas, NumPy
- **시각화:** Plotly
- **머신러닝:** Scikit-learn
- **모델:** RandomForestClassifier
- **전처리:** MultiLabelBinarizer를 활용한 기술 스택 원-핫 인코딩

### ML / 딥러닝 / LLM 선택

- **선택:** ML
- **이유:** 이번 프로젝트는 표 형식의 채용공고 데이터를 기반으로 직무를 분류하는 문제이므로, 무거운 딥러닝보다 Scikit-learn 기반의 머신러닝 모델이 적합하다. 또한 수업 시간 안에 구현하고 Streamlit에서 안정적으로 실행하기 위해 가볍고 해석 가능한 ML 모델을 우선적으로 사용한다.

## 4. 예상 난관 1가지

가장 큰 난관은 **기술 스택 데이터의 표기 방식이 일정하지 않을 수 있다는 점**이다.

예를 들어 같은 기술이라도 다음과 같이 다르게 표기될 수 있다.

- Python
- python
- PYTHON
- Python3
- 파이썬

또한 공고마다 기술 스택이 쉼표, 슬래시, 공백 등 서로 다른 방식으로 구분되어 있을 수 있다.

따라서 데이터 분석과 모델링 전에 다음과 같은 전처리가 필요하다.

- 모든 기술명을 소문자로 변환
- 앞뒤 공백 제거
- 같은 의미의 기술명 통일
- 쉼표 기준으로 기술 스택 분리
- 너무 적게 등장하는 기술은 제외
- MultiLabelBinarizer를 활용해 0과 1의 형태로 변환

이 과정을 통해 기술 스택 데이터를 머신러닝 모델이 학습할 수 있는 형태로 정리할 계획이다.
